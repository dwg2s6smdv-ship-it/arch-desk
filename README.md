# 设总工作台

住宅项目设计总负责人（设总）的项目管控看板。**纯静态页面，双击 `index.html` 即用，不依赖任何后端或账号。**

同时管多个项目时，靠脑子记不住，靠微信记不牢。这个看板只回答四件事：今天催谁、每个项目卡在哪一步、哪些坑不能再踩、去年的经验去哪了。

## 四个板块

| 板块 | 内容 | 特点 |
|---|---|---|
| 01 我的今日雷达 | 最紧急的待办，逾期自动置顶 | 唯一保留勾选的地方 |
| 02 项目节点掌控 | 前期方案强排 / 投标项目 / 项目报规 三段 SOP，挂模板与清单 | 只取用，不打卡 |
| 03 设总防坑清单 | 强排指标、专业打架、报规防线、实体催办墙 | 红框警示，绿框做法 |
| 04 归档与复盘 | 年度项目复盘台账入口 | 经验回填，防坑清单才越来越厚 |

## 怎么用

**在线打开**：`https://dwg2s6smdv-ship-it.github.io/arch-desk/`

**本地打开**：下载 `index.html`，双击即可，不需要联网。

**数据说明**：`data.js` 里存着 2026-11-18 的数据快照（17 条）。勾选、编辑、新增、删除都会生效，但只保存在**当前浏览器**（localStorage），刷新还在，换设备不同步。想恢复初始状态，点页脚「恢复为快照」。

## 文件结构

```
.
├── index.html     页面骨架
├── style.css      样式
├── data.js        数据快照（17 条记录）
├── app.js         交互逻辑
└── README.md
```

四个文件同目录放置即可运行，不要单独拷走 `index.html`。

## 路径约定

所有模板与清单指向同一个根目录，换电脑只改一处：

```
D:/_项目管控/
├── 01_强排/     强排前置条件核对单、指标算账表、总图排布自检表
├── 02_投标/     交标节点倒推表、标书封装清单、PPT 模板库
├── 03_报规/     报规前置图纸核对表、指标沟通备忘、面积对账单
└── 04_归档/     年度项目复盘台账
```

## 更新数据

两条路：

1. **改快照**：用编辑器打开 `data.js`，里面是 `var SNAPSHOT = [...]` 的 JSON 数组，字段为 `id / name / zone / kind / desc / path / status / owner / due / order`，改完保存提交即可。
2. **重新导出**：从 WorkBuddy 资料库的数据表导出最新记录，替换这一段 JSON。

## 技术说明

- 纯静态，零依赖：无 CDN、无字体请求、无统计脚本
- 原生 ES5 + DOM，不经构建，改完刷新即可
- 响应式：桌面三列，移动端单列
- 支持打印（会隐藏所有按钮）
- 数据可以「导出备份」为 JSON，方便自己留档
- 首次打开若样式缺失，确认 `style.css` 与 `index.html` 在同一目录

个人自用工具，随取随用。
